# Roadmap

Each phase requires the [testing and acceptance gates](testing.md). Track actual completion in [progress](progress.md).

| Phase | Deliverable | Demonstration |
| --- | --- | --- |
| 0 | Project setup | Review the local branch, documentation and delivery gates. |
| 1 | Frontend foundation | Start and build the typed frontend shell and run a smoke test. |
| 2 | Visual design system | Inspect responsive type, surfaces, focus and control states. |
| 3 | 3D rendering engine | Render a cleared test asset and exercise the fallback. |
| 4 | Cinematic hero | Play and skip the opening reveal. |
| 5 | Scroll-driven experience | Move forward and backward through camera beats using native scroll. |
| 6 | Interactive showroom | Inspect the car and restore the starting view. |
| 7 | Vehicle configurator | Choose a finish and verify the scene and textual summary agree. |
| 8 | Performance experience | Demonstrate adaptive rendering on a constrained device. |
| 9 | Photography mode | Frame and export an image with permitted assets. |
| 10 | Vehicle collection | Switch models and verify valid options for each. |
| 11 | Motion and visual polish | Review transitions, interruptions and reduced motion. |
| 12 | Optimization and testing | Repeat performance traces and regression tests on target devices. |
| 13 | Production release | Obtain release approval and verify the human-authorized deployment. |
